# DIOFANY’S Bakery — Project Charter

**Project name:** DIOFANY’S Bakery — Inventory & Accounting Tracker (MERN MVP)

**Short description:** A simple web app to help a bakery manage products, inventory, sales, expenses and get basic financial insights (gross/net sales, COGS, gross & net profit).

**MVP goals:**
- Track products, inventory, and sales in real time.
- Calculate gross sales, net sales, COGS, gross profit and net profit automatically.
- Provide a small dashboard (KPIs + charts) and basic CRUD for products, sales and expenses.
- Host using free-tier cloud: Vercel (frontend), Render (backend), MongoDB Atlas (M0).

**Success criteria (what “done” looks like):**
- Backend with documented API reachable locally.
- Frontend skeleton that can list/add/edit/delete products.
- Sales recording reduces stock and records computed values (gross/net/COGS).
- Basic dashboard showing KPIs.
- MongoDB Atlas M0 cluster provisioned and .env.example in repo.
- Phase 1 docs (charter, requirements, data model, API spec, wireframes, acceptance checklist) completed and reviewed in signoff meeting.
